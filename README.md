## 🚀 Platform Capabilities

1. **SANS 10139 Service Request & Lifecycle Management**
   - Interactive intake wizard with urgent emergency triage.
   - Stage-gate tracking from submission, review, survey scheduling, quotation, WIP, to certified sign-off.

2. **Automated Photographic Condition Reports**
   - Pre-Work & Post-Work condition records with photo evidence tagging.
   - Version-controlled reports with client acknowledgment and PDF export.

3. **Technical Documents & CAD Evidence Vault**
   - Comprehensive multi-format vault supporting DWG, DXF, IFC, STEP, RVT, RFA, PDF, Excel, Word, and Archives.
   - 25+ technical document categories (Site Drawings, Single-Line Diagrams, Cause & Effect Matrices, SANS Certificates, As-Built drawings).
   - Interactive CAD previewer, revision history tree, SHA-256 integrity hashing, and quarantine security.

4. **During-Work Video Evidence Desk**
   - Timestamped video recordings of sensor tests, cabling integrity, and panel commissioning.
   - Engineering review approval workflow with direct SANS report inclusion.

5. **Customer & Administrative Portals**
   - Customer self-service portal for tracking progress, viewing reports, and communicating with assigned engineers.
   - Comprehensive Administrative Command Center for managing requests, technical documents, site visits, and compliance audits.

## 💻 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/BETHUELTHIPE/Audrin-Fire-Engineers.git
   cd Audrin-Fire-Engineers
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
